# Ocean Crew 海洋形象资产包

12 种海洋生物、13 色、独立 SVG、透明 PNG、眼睛定位与共享渲染器的源数据。插件里的
`ocean-crew/src/client/look/marine-assets.ts` 由本目录生成，构建产物随插件发布。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `svg/marine-*.svg` | 12 个独立、透明、100×100 viewBox 矢量头像；默认蓝色，可无限缩放 |
| `png-128/marine-*.png` | 每种头像一张 128px 透明 PNG；适合临时图片头像或常规图片展示 |
| `marine-assets.mjs` | 无第三方依赖的 JS 资产数据与 SVG 渲染函数；浏览器、Node、打包器可用 |
| `catalog.json` | 全部身体、纹理、眼睛路径与默认选择 |
| `palette.json` | 13 色配置，含浅/深主题的头像填色与极光渐变 |
| `eye-layout.json` | 每只动物的眼睛数量、位置、边界、眼白、瞳孔及闭眼路径 |

每个独立 SVG 都有 `mb-body`、`mb-markings`、`mb-eyes` 三层。眼睛使用真实的白色前景与深蓝瞳孔，不是挖透明洞。每只眼睛提供 center/bounds 和闭眼路径，瞳孔被裁切在眼白内。

- `blink: true` 输出闭眼形状；`false` 输出睁眼。二者不会同时画出。
- `gaze` 仅移动有独立瞳孔的眼睛，并受眼白 clip 限制；鲸鱼没有独立瞳孔，不拆成双眼。
- 身体晃动、跳动、完成动作由应用的状态系统处理，本包不新增动画循环。
- 单体图没有主 Bot 星标、管理员标志或运行状态点；由界面单独叠加。

## 接入约定

1. 形象、色板与眼睛数据只在 `marine-assets.ts` 渲染，选择器、选中轮廓和 README 配图共用同一渲染源。
2. 身体含多个闭合子路径，按分别填充的并集处理；套 `evenodd` 会让鳍、腿或触手重叠处镂空。选中环取身体整体剪影，不把眼白或腹部当外边框。
3. 新建 Bot 的默认外观是 `marine-whale + deepseek`；随机默认只用于新表单，不重排既有默认表。
4. 色板共 13 个 ID，`deepseek` 是默认蓝鲸的选中色。
5. 照片头像优先于形状；切回内置形象时明确退出照片。`picker-preview.html` 是独立资产工具，不连 DSH、不创建 Bot。
